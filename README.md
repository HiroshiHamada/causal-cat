### 内容

第1～第3章に関しては補足はありません

第4章に対応する補足資料
- 回帰係数の正体
- シンプソンのパラドクスが生じる仕組み
- クロス表からのOLS係数の計算

第5章に対応する補足資料
- 回帰でATEが推定できる理由
- 潜在的結果を確率変数として扱う場合

第6章に対応する補足資料
- 共変量の調整が機能する理由
- 回帰式に共変量を加えるとATEが推定できるか
- 逆確率重み付け推定量の不偏性と一致性
- 逆確率重み付けの計算過程（割引クーポンの例）
- 傾向スコアによるバランシング性
- 傾向スコアマッチングでATEを推定する条件
- 二重にロバストな推定

第8章に対応する補足資料
- 調整化公式の導出
- 調整化公式と共変量による調整との一致
- チェーン構造における理論上の平均因果効果

第9章に対応する補足資料
- 操作変数推定量と確率収束
- 操作変数の二つの定義：因果推論流と計量経済学流
- フロントドア基準による調整

第10章に対応する補足資料
- 反実仮想の練習問題の解答
- 反実仮想の計算とベイズ統計
- 潜在的結果モデルと構造的因果モデルの反実仮想の違い

第12章に対応する補足資料
- $pR<1$ の領域における相対的剥奪モデルのパラメータリカバリー
